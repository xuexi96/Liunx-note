# frp的使用


## 软路由主机

###  下载frp
https://github.com/fatedier/frp/releases



创建目录
```bash
mkdir -p /usr/frp/

cd /usr/frp/
```
根据自己的系统下载
```bash
wget https://github.com/fatedier/frp/releases/download/v0.71.1/frp_0.71.1_linux_arm64.tar.gz
```

解压文件
```bash
tar -zxvf frp_0.71.1_linux_arm64.tar.gz

cd frp_0.71.1_linux_arm64
```
